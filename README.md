🌐 Proyecto Next.js - Seguro Obligatorio
Esta aplicación web está desarrollada con Next.js 15, React 19 y TailwindCSS. Su propósito es ofrecer una plataforma clara y moderna para la gestión y consulta del seguro obligatorio.
Cuenta con animaciones suaves usando AOS y un diseño responsivo mediante TailwindCSS para una experiencia óptima en múltiples dispositivos.

🚀 Tecnologías utilizadas
⚡ Next.js 15 – Framework React con Server Side Rendering y generación estática.
⚛️ React 19 – Última versión de la librería para interfaces de usuario.
🎨 TailwindCSS 3.4 – Framework CSS utilitario para estilos rápidos y flexibles.
🎞️ AOS – Animaciones al hacer scroll para mayor dinamismo.
🛠️ @tailwindcss/aspect-ratio – Plugin para controlar proporciones de elementos visuales.
🔢 unique-names-generator – Generador de nombres únicos, posiblemente para usuarios o identificadores.
